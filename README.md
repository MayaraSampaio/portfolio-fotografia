# 🌸 Portfólio de Fotografia — Felipa Sato

Este projeto apresenta o **portfólio profissional de Felipa Sato**, uma fotógrafa especializada em retratos, estúdios e casamentos.  
O site foi desenvolvido com **HTML5**, **CSS3** e **Bootstrap 5**, com foco em **design responsivo**, **navegação intuitiva** e **valorização visual das imagens**.

---




## 🖼️ Demonstração

O site contém:
- Uma **introdução pessoal** com foto e descrição profissional.  
- Uma **galeria em carrossel** com fotografias de **casamentos** e **retratos de estúdio**.  
- Uma **barra de navegação** para diferentes páginas (Home, Serviços, Blog e Contato).  
- Um **rodapé com links de redes sociais** e créditos de desenvolvimento.  
- Um **modal interativo** para visualização de imagens ampliadas.

---

## ⚙️ Tecnologias Utilizadas

- **HTML5** — estrutura semântica do site  
- **CSS3** — personalização de estilos  
- **Bootstrap 5.3.8** — responsividade e componentes (navbar, carrossel, modal)  
- **JavaScript (Bootstrap Bundle)** — interações (carrossel e modal)
